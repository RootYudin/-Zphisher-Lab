## 📖 Overview
Zphisher is a phishing simulation tool.  
In this project, I explored how phishing attacks are crafted and delivered, and studied **defensive measures** like email filtering, awareness training, and multi-factor authentication (MFA).

---

## 🛠️ Learning Outcomes
- Understood how phishing pages are generated.  
- Learned how attackers trick users into revealing credentials.  
- Studied defensive strategies: email filtering, MFA, and awareness training.  

---

## ⚠️ Disclaimer
This project is for **educational and ethical purposes only**.  
No real phishing attacks were performed — the focus is on **understanding and defense**.
